四步完成一次交付
上传工资表
支持 xlsx / xlsm / xls / csv（CSV 自动识别 UTF-8 / GBK），自动挑选最像工资表的 Sheet 并定位表头行。
确认列映射
系统按 420 条别名词典自动归一列名（工号 / 员工编号 / 职工号 等写法均可识别），必填项红色标注，可手工修正。
设定参数并核算
核算年度、月份（单月表必填）、参保城市（留空则按表内城市列）、年终奖计税方式（默认自动择优）。
查看校验并下载报表
闪电校验输出异常清单；核算结果页下载 7-Sheet 标准化报表（算薪明细 / 月度汇总 / 年度汇总 / 社保公积金 / 异常清单 / 差异比对 / 政策溯源）。
闪电校验规则（12 类）
错误 应发勾稽不平 · 个税反算不符 · 差异比对超容差 · 扣除项超标 · 基数超上限
警告 基数低于下限（保底补差） · 环比波动超阈值 · 月度个税为负 · 缺少累计接续数据
提示 年终奖计税方式建议 · 入离职当月口径提示 · 宽表空月跳过说明
批量与命令行
单文件核算：python cli.py run 工资表.xlsx --year 2026
集团批量：python cli.py group 目录/ --year 2026 -o outputs/
启动界面：python cli.py serve --port 8765
